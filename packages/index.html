Change packages. For the items no configuration change can move: why, with the evidence, what would unblock each, and the test that will count once the software is replaced. Written by a rule from the ledger; nothing here is applied.

Some of the estate cannot be migrated by changing a setting: the software lists no post-quantum algorithm for the job. OMB M-26-15 says such systems must be identified and given priority for replacement; in NIST's plan this is mitigation, beside migration. Each package below is that identification for one item, built from the CBOM and the runtime's own list of what it supports. No model wrote these. The rule package/supplier/1 reads the blocker, the queue, the snapshot and the CBOM entries; each package is an event on run 01M5G36BJANYEKWVTHDVNQ98YE, over scan 01M5FYXR40S3FRWW9NXYVA5A7K.
