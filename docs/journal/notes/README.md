# Technical notes

One question per note. Read `../STYLE.md` before writing one. A note is written
when the project can answer its question with measured or cited evidence.

A note's number is its place in the plan below and never changes; notes are
written out of order, as the project becomes able to answer them. Note 00 is
the overview and is rewritten as the project advances.
