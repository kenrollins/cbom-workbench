# Roadmap

What the workbench does today, and what comes next. The working plan behind it is kept privately; this
is its public summary.

## Built

- **Discovery** on three layers: the wire (testssl.sh, ssh-audit, OpenSSL 3.5 probes), images
  (cbomkit-theia and the workbench's own file reader) and code (a rule pack for Ruby, with a model
  judging each candidate call site); passive capture with Zeek for what clients offer.
- **The CBOM** (CycloneDX 1.6) rebuilt from an append-only, hash-chained ledger with ML-DSA-65-signed
  checkpoints; any other tool's CBOM can be imported and scored against the same answer key.
- **Structure:** a dependency chain for every listener — service, listener, asset, file — and the
  owner's facts, labelled supplied.
- **Managed:** OMB M-26-15 as a policy pack checked against the memo's text; queues, deadlines and
  supplier and validated-module blockers; change packages for what no setting can move.
- **The plan:** what depends on what, what comes first and in what order, computed from the CBOM, with
  the traps a plan from a spreadsheet falls into, and what-ifs.
- **Resolution:** changes rendered by rule or drafted by a model, rehearsed on a copy, checked against
  every kind of client, approved by a person and proved on the wire twice.
- **Models by measurement:** six roles, each with a floor written before the run; a role goes to a model
  only when one reached it.

## Next

- **When must each step start?** Lead times per replacement and upgrade, so the plan becomes a
  schedule: the latest start for every step, and which are already at risk.
- **A plan to take to a meeting:** an export of the ranked steps, dependencies, deadlines and reasons.
- **The full agency:** every service the policy covers changed, re-scanned and timed.
- **A held-out variant of the test estate,** scored once, so the method is not tuned to its own key.
- **The offline bundle:** everything needed to run the workbench on a host with no network, rehearsed
  from an empty machine.
- **Ask the CBOM** (research): questions about the estate and the plan answered by a model and checked
  against the rules.
