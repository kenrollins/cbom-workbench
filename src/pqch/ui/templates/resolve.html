Adding the hybrid group to a server changes nothing for a client that does not offer it. So the verifier runs a pair: a client offering only the hybrid group must be accepted, and a client offering every classical group — not just the two the server used to have — must be refused. Both hold: enforced. Only the first: enabled-not-enforced, a real state and not a pass. The ledger behind it is hash-chained and checkpointed with ML-DSA-65 by a signer that keeps the key where nothing else can read it. What "verified" means · What an auditable record contains.
