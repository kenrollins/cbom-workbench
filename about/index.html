About. What this project is, what it is not, and the disclaimer in full.

What this project is

cbom-workbench is a personal exploration by Ken Rollins into one question: what does a fully developed cryptography bill of materials let an organization do? Federal policy now requires the inventory. This project builds one from evidence and then puts it to work — prioritizing, detecting change, and carrying out and verifying an algorithm change.

What this project is not

  • Not an official Dell product. There is nothing to buy.
  • Not a Dell reference architecture. This work has not been produced, endorsed or reviewed through any official Dell channel. Views and findings are the author's own.
  • Not a replacement for commercial discovery platforms. Those are fielded products that observe live estates. This is an open exploration of what the inventory enables.
  • Not a compliance determination. Nothing here certifies that a system meets a federal requirement.
  • Not a vulnerability report. Where public source code is analyzed, the results describe what an inventory reveals.

Disclaimer

This site and the repository it is built from are a personal exploration, published under the Apache-2.0 licence. They are not an official Dell product, reference architecture or Dell position, and have not been produced, endorsed or reviewed through any official Dell channel. Nothing here is a compliance determination, a security assessment of any named system, or a vulnerability disclosure. Numbers are measurements on the hardware named beside them.

How it is built, what it measured and what it learned are in the field notes.
