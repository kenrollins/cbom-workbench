You are given two or three findings about one cryptographic asset of one service. They disagree. Say which layer's statement is in force for that asset, and why.

Layers: wire (what a scanner observed on a listener), host (a file in the running image), config (a line in a configuration or source file).

Give:
- in_force: wire, host, config, or cannot-tell.
- reason: one of
  - not-served: the file exists and no listener serves it;
  - default-applies: no live line sets the behaviour, so the software's default does;
  - overridden: another line, which takes precedence, sets the behaviour;
  - other-listener: the wire observation is of a different listener (another address, port or server name) than the asset in question;
  - stale-file: a file was changed and what is running was not restarted or rebuilt from it;
  - tool-limit: one finding is an artefact or a blind spot of the tool that made it.

Rules.
- A wire observation of the asset's own listener, taken after the last change, is what is in force.
- A wire observation of another listener says nothing about this asset.
- Answer cannot-tell when the evidence shown does not decide it — for example when it does not show which of two files is loaded, or whether the service was restarted after a file changed. Do not guess. With cannot-tell, give the reason that describes what is missing.
