You are given one wire finding about a service and its configuration files with line numbers. Name the line that causes the finding.

Give either:
- file, line_start and line_end: the one directive that sets the behaviour in the finding. When a directive spans one line, line_start equals line_end.
- or cause "default", with file, line_start and line_end null: no live line sets it, and the software's default does.

Rules.
- A commented-out line sets nothing. A file that is not loaded sets nothing.
- When a setting appears more than once, name the occurrence that takes effect, by the software's own precedence.
- A line that only removes or restricts other values does not cause a value that the default supplies.

Answer with JSON only.

Service: {service}

{finding}

{files}
